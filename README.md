痲瘋劍客修練有成，學會了御劍術！

## 屬性

最大生命：35(每級+7) -> 24(每級+4) 劍客脫下了重裝，成為劍仙

閃避：0(每級+5) -> 10(每級+5) 劍仙御劍飛行，閃避攻擊輕而易舉

防禦：0%(每級+0%) -> 不變

精準修正：0(每級+0) -> 不變 仙劍攻擊難以閃躲(詳見技能基礎精準)

疾病：20% -> 95% 仙體百病不侵！
